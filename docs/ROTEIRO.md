- **Fotos do arsenal no Supabase Storage (17/11/2026)**: mesmo com o carregador próprio (commit 72883dd), as fotos não apareciam em produção. O Wikimedia responde HTTP 429 ("Too many requests", `retry-after: 120`) por IP às miniaturas fora do cache dele, e o carregador pedia larguras variadas (250–1920 px) a cada card. Agora `gravarEquipamento` copia a miniatura de 960 px de cada foto para o bucket público `fotos` (`lib/imagens/espelho.ts`, com o `WIKIMEDIA_USER_AGENT`) e grava a cópia em `midias.miniatura_url`; o carregador devolve a cópia como está e, para foto ainda sem cópia, usa só a miniatura de 960 px do Commons. Se a cópia falhar, a gravação segue com a URL do Commons. Para as fotos já gravadas: `pnpm arsenal:espelhar-fotos` (idempotente; `--seco` só conta).
